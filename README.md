==================================================

MAIN OBJECTIVE

A customer enters the restaurant.

Every table has a unique QR Code.

Customer scans the QR Code.

The QR opens the restaurant web application directly.

Customer browses food items and places an order.

The owner receives the order instantly.

The owner manages the complete restaurant from the Owner Dashboard.

IMPORTANT:

The owner should never require:

- Code modification

- Developer support

- Manual database editing

- Editing files

Everything must be controlled from the application UI.

The complete restaurant operation should work like a CMS.

# Shivansi Restaurant & Sweet Shop — Agent Guide

## Architecture

- **Framework**: React 19 + [TanStack Start](https://tanstack.com/start) (SSR/SSG)
- **Router**: TanStack Router (file-based, auto-generated `routeTree.gen.ts`)
- **Database & Auth**: Supabase (Postgres + Row Level Security + Realtime)
- **Styling**: Tailwind CSS v4 with oklch design tokens (see `src/styles.css`)
- **Runtime**: Cloudflare Workers via Nitro (configured in `vite.config.ts`)
- **Package Manager**: Bun

## Project Structure

```
src/
├── routes/          # File-based routes — __root.tsx is the shell
├── components/      # Shared UI components (shadcn/ui base + custom)
├── lib/             # Utilities, cart context, Supabase helpers
├── hooks/           # Custom React hooks
├── integrations/    # Supabase client + auth attacher
└── assets/          # Static assets bundled by Vite
public/
├── robots.txt       # Crawler rules
├── sitemap.xml      # Page sitemap
└── llms.txt         # LLM / AI crawler context
```

## Dev Commands

## Key Conventions

- **Colors**: Never hardcode. Use oklch CSS tokens from `src/styles.css`.
- **Server functions**: Must live in files co-located with routes; protected by CSRF middleware.
- **Supabase RLS**: All DB mutations rely on Row Level Security. Never bypass with service role key on the client.
- **Route generation**: Never manually edit `src/routeTree.gen.ts` — it is auto-generated by TanStack Router.
